# Privacy Policy

**Last Updated:** October 13, 2025
**Effective Date:** October 13, 2025

## Introduction

Warren Burrows ("we," "us," or "our") operates the RAMCO MCP Server (the "Service"). This Privacy Policy explains our practices regarding data collection, use, and protection when you use our Service.

**Key Privacy Principle:** We are committed to protecting your privacy. We do **not** store, log, or retain any of your personal data, API keys, queries, or RAMCO data.

## Information We Do NOT Collect

We want to be very clear about what we **do not** collect:

- **API Keys:** Your RAMCO API keys are never stored, logged, or retained
- **Search Queries:** Your queries and requests are not logged or saved
- **RAMCO Data:** Data that passes through our Service is not stored
- **Personal Information:** We do not collect names, emails, or contact details
- **Usage Analytics:** We do not track your usage patterns or behavior
- **IP Addresses:** We do not log or store IP addresses (except for rate limiting, see below)
- **Cookies:** We do not use cookies or browser storage
- **Tracking:** We do not use analytics, tracking pixels, or similar technologies

## How the Service Works

The RAMCO MCP Server operates as a **pass-through integration**:

1. You send a request from Claude (or another MCP client) to our Service
2. Your request includes your RAMCO API key in the headers
3. Our Service forwards your request to the RAMCO API
4. The RAMCO API responds with data
5. Our Service forwards the response back to you
6. **No data is stored at any step**

The Service exists only in memory during the request and is discarded immediately after the response is sent.

## Rate Limiting

To protect service availability and prevent abuse, we implement rate limiting based on IP addresses. This is the **only** data temporarily held in memory:

- **What:** IP address and request count
- **Why:** To enforce rate limits (100 requests per minute per IP)
- **How Long:** Cleared from memory after 1 minute
- **Not Stored:** This data is never written to disk or logs

## No Third-Party Services

Currently, we do **not** use any third-party services for:

- Analytics or tracking
- Error monitoring
- Logging or monitoring services
- Marketing or advertising

If we add third-party services in the future, we will update this Privacy Policy and provide advance notice.

## API Keys and Security

**Your RAMCO API key security is critical:**

- **In Transit:** API keys are transmitted via HTTPS encryption
- **In Memory:** API keys exist in memory only during request processing
- **Not Logged:** API keys are never written to logs or disk
- **Not Stored:** API keys are discarded immediately after use
- **Your Responsibility:** You are responsible for keeping your API key secure

**Best Practices:**
- Never share your API key publicly
- Rotate your API key regularly
- Monitor your RAMCO account for unauthorized access
- Report any suspected security issues to [amsmcp@warrenburrows.dev](mailto:amsmcp@warrenburrows.dev)
