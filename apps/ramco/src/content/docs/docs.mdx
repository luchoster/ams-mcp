## Introduction

**RAMCO MCP Server** is a **Model Context Protocol (MCP)** server that transforms the RAMCO API into an association analytics powerhouse. Built for analyzing entire memberships (10,000+ members) to provide actionable insights for member engagement, retention, and growth.

Key features include:

- **Bulk Analytics** - Process 10,000+ members in seconds
- **Engagement Scoring** - AI-powered member engagement analysis
- **Churn Prediction** - Identify at-risk members with intervention plans
- **Payment Analytics** - Financial health analysis with aging reports
- **Natural Language Search** - Query members using plain English
- **Real-time Processing** - No Redis required, HTTP transport optimized

## Quick Example

Here's how easy it is to get started with RAMCO MCP:

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "ramco": {
      "transport": "http",
      "url": "https://ramco.amsmcp.dev/http",
      "headers": {
        "Key": "your-ramco-api-key-here",
        "ramco-association-id": "your-association-guid-here"
      }
    }
  }
}
```

Once configured, you can ask Claude:

```
"Give me a complete health assessment of our association"
```

And get instant analytics:


## Architecture

- **HTTP Transport** - Recommended, no Redis dependency
- **SSE Transport** - Available for streaming responses
- **Pass-through Design** - No data storage, API keys in memory only
- **Type-safe** - Built with TypeScript and Zod validation
- **Automatic Pagination** - Handles large datasets seamlessly
